# CnizOS Life — бесплатный пробный деплой

## Важно

- Архив очищен от `.env` и локальных SQLite-баз. Демо-данные из них не входят в этот архив.
- Не загружай `.env`, токены, пароли, дампы БД и реальные пользовательские данные в GitHub.
- Бесплатные тарифы подходят для тестового/личного проекта, но не гарантируют постоянную доступность. Render Free засыпает после простоя, а его бесплатный PostgreSQL удаляется через 30 дней. Для постоянных данных используй отдельный PostgreSQL-провайдер с подходящим бесплатным тарифом и регулярно делай резервные копии.
- Zoro Bridge управляет компьютером и требует отдельной настройки и постоянного исходящего WebSocket-подключения. На бесплатном backend, который засыпает, соединение может обрываться.

## Рекомендуемая схема

1. GitHub — приватный репозиторий исходников.
2. Render Static Site — интерфейс React/Vite (`frontend`).
3. Render Web Service — FastAPI (`backend`).
4. Отдельная PostgreSQL-база с бесплатным тарифом — например Neon; проверь актуальные лимиты/условия перед созданием.

## Настройка frontend на Render

- New → Static Site → подключи репозиторий.
- Root Directory: `frontend`
- Build Command: `npm ci && npm run build`
- Publish Directory: `dist`
- Environment variable: `VITE_API_URL=https://АДРЕС-ТВОЕГО-API/api/v1`

Vite подставляет `VITE_API_URL` во время сборки, поэтому после изменения переменной нужно пересобрать сайт.

## Настройка backend на Render

- New → Web Service → тот же репозиторий.
- Root Directory: `backend`
- Build Command: `pip install -r requirements.txt`
- Start Command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
- Environment: `DATABASE_URL`, `JWT_SECRET`, `CORS_ORIGINS`.
- `DATABASE_URL` должен быть PostgreSQL URL, совместимым с SQLAlchemy async-драйвером, обычно начинаться с `postgresql+asyncpg://`.
- `JWT_SECRET` сгенерируй новый случайный длинный секрет. Не используй значение из старого `.env`.
- `CORS_ORIGINS` — точный HTTPS-адрес frontend, без завершающего `/`.

## Обязательная проверка перед запуском

1. В этом подготовленном архиве CORS уже использует список `CORS_ORIGINS`, а не wildcard вместе с credentials. Укажи точный адрес опубликованного frontend.
2. В этом архиве добавлена переменная `COOKIE_SECURE`. На production с HTTPS выставь `COOKIE_SECURE=true`; для локальной разработки оставь `false`. Frontend/API должны работать по HTTPS.
3. В коде должны быть корректно обработаны WebSocket URL, CORS и API URL для реальных адресов. Проверь `/health` и `/docs` после запуска.
4. Создай аккаунт через `/setup` только после подключения постоянной базы. Если база потеряет данные, аккаунт и записи пропадут.
5. Не импортируй старую SQLite-базу вслепую: сначала проверь схему и сделай резервную копию отдельно.

## Безопасность

- Не включай в публичный репозиторий `.env`, базы данных, резервные копии, токены Bridge/Zoro и JWT-секреты.
- Если исходный `.env` уже попадал в публичный репозиторий, удали его из истории и немедленно смени все секреты.
- Не используй демонстрационный пароль из QUICKSTART в публичном сервисе.
